# Project cover artwork

Created with the built-in GPT Image tool. These are conceptual illustrations, not product screenshots or architecture diagrams. The site displays all imagery in grayscale. Originals remain in the image generation outputs; this repository stores optimized WebP assets.

## Shared generation prompt

Use case: stylized-concept. Asset type: professional AI engineer portfolio project cover, wide landscape 3:2. Create one premium editorial 3D still-life illustration, physically rendered, strictly monochrome black, white and neutral gray. Seamless pale gray studio background. Black obsidian, brushed silver and matte white materials, crisp geometry, refined soft shadows, cinematic side light, subtle fine film grain. Centered sculptural composition, plenty of space around all sides, readable at thumbnail size. This is a conceptual illustration, not an actual product screenshot or precise data diagram. No text, letters, numbers, logos, watermarks, colored pixels, gradients in hue, or recognizable brand marks. Sophisticated contemporary gallery aesthetic.

## Final refinements

The built-in GPT Image edit tool refined four covers using their generated originals:

- EY Voice: remove all words, icons, and logos from the tiles and earcup. Keep the headset and waveform. Use blank white ceramic tiles and neutral black-and-white materials.
- EYLAR: remove all text, numbers, labels, and arrows from the books, retrieved page, answer orb, and foreground. Keep the archive, lens, and connecting threads in a wide 3:2 composition.
- Portfolio AI: extend the canvas to a wide 3:2 composition without cropping the objects. Replace warm metallic tones with neutral silver, black, and white.
- BottegaAI: use a wide 3:2 composition and a simple neutral studio background. Remove the glass on the right. Keep the plate, menu, cutlery, waveform, and order tokens in black, white, and silver.

WebP exports use a 960-pixel width and quality 80. Each file is 960 × 640. Next.js supplies responsive image sizes and lazy loading.
